# Hi, I'm A. Rahsepar

Network engineer and Linux/Android developer based in Shiraz, Iran. I spend most of my time working with custom Android kernels, device bring-up, OpenWRT, and small pieces of automation that make debugging less painful.

## What I work with

- **Linux kernels** — Android GKI, MediaTek platforms, device trees, build configs, and stable updates
- **Android bring-up** — device/vendor trees, HALs, SELinux policies, recovery, and boot issues
- **OpenWRT and networking** — board support, drivers, firewall rules, VPNs, QoS, and RouterOS
- **Automation** — Bash and Python scripts for builds, device testing, validation, and maintenance
